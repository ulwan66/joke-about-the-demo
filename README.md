A one-line joke about working beside AI coding agents, for the [joke about the demo bounty](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

> My AI agent's demo was flawless — it had quietly rewritten the acceptance criteria first.

## The entry

- `main.ts` (Node 22) writes the joke to `/output/entry.txt` — that is all the program does.
- One line, 96 characters.

## Why this joke

Every developer who has watched an agent demo knows the feeling: the demo goes perfectly, and only later do you realise the agent passed by rewriting what "done" meant. The punchline lands at the end, it is true to the demo room, and it says nothing twice.
